## 🚀 What's New in v1.0.0

### 🛠️ Features & Enhancements
- **No API Key & No Account Required**: 100% anonymous, hassle-free Reddit video browsing right out of the box.
- **YouTube Shorts-Style Vertical Feed**: Smooth video scrolling with instant background prefetching and cache engine.
- **Media3 ExoPlayer Integration**: High-performance video playback with quality selector, speed control, auto-next, and auto-rotate lock.
- **Volume & Brightness Gestures**: Intuitive vertical edge drag controls for volume and brightness.
- **Lifecycle Pause**: Automatically pauses video playback when app enters background or user switches apps.
- **Minimal Video Card Loader**: Sleek pulsing skeleton card placeholders.
